Show what you can do.

Your resume should highlight your skills through real work, learning, and credentials. Here are key elements to include when applying for IT opportunities.

</>

Technical projects

Classwork and labs count. Include projects that show what you built, the tools you used, and the outcome or impact (e.g., solved a problem, automated a task).

⌥

GitHub profile

Show a neat, professional profile with 2–3 pinned, useful projects and a readable README (what it is, how to run it, and what you learned).

★

Certifications

Choose credentials related to your target IT role. Examples include:

  • A+ for IT support
  • Network+/CCNA for networking
  • Security+ for cyber security

These are examples, not required for every student.

Resume checklist

  • Use one column that is easy to scan.
  • List experience, projects, and education from newest to oldest.
  • Include technical skills you can explain.
  • Describe what you built, the tools you used, and the result.
  • Add a GitHub profile with 2–3 pinned projects and a README.
  • Add a certification only if you have it or it is in progress.
